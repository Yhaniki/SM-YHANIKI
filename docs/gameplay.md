# 遊戲與譜面編輯器功能

本文件整理 SM-YHANIKI 相較於基礎 StepMania 3.9 的主要操作與功能擴充。

## 一般模式

| 快速鍵 | 功能 |
| --- | --- |
| `F4` | 更新指定歌曲 |
| `F5` | 快速重讀歌曲 |
| `Ctrl + F5` | 指定資料夾快速重讀歌曲 |

主要功能：

- Note 流速不會因歌曲倍速而改變。
- 結算成績畫面顯示歌曲倍速。
- 修正使用 AUTOPLAY 或譜面沒有 Note 時的崩潰問題。
- Hold 結尾可使用獨立判定模式，並顯示判定時間差。
- 影片播放速度會跟隨歌曲倍速調整。
- 支援以 `Shift + F8` 顯示 AutoPlayCPU。
- 支援自訂 NoteSkin 長條發光效果。
- 選歌畫面可以顯示目前歌曲的背景圖。
- 支援打擊軌道背板與背板透明度設定。
- 第一次載入歌曲（或快取版本更新後需要重建快取時）會用多個執行緒同時處理。執行緒數可在 `Data/StepMania.ini` 的 `SongLoadThreads` 設定：`0` 為自動（CPU 執行緒數的兩倍，最多 16），`1` 為逐首載入。

部分功能需要主題配合修改，詳情請參閱主題相關文件及素材包中的設定。

## 譜面編輯器

### ddrtime 相關功能

- BPM 與 STOP 可顯示至小數點第三位。
- BEAT 與時間可顯示至小數點第六位。
- 箭頭間距支援 `0.25x` 至 `8x`，並以 `0.5x` 為主要調整單位。
- 支援負數 STOP，以及透過 `N`、`Ctrl + N`、`Alt + N` 進行轉換。
- 支援 192nd 箭頭編輯。
- 支援直接編輯 BPM 與 STOP。
- 編輯時會建立 `FileBackup` 備份資料夾。
- 支援自動儲存及自訂儲存間隔。
- 支援 Reverse 編輯環境下的直覺操作。
- 可在 Edit Song Info 中編輯 DisplayBPM。

### 其他修正與擴充

- 修正影片預覽播放位置。
- 修正變速歌曲的 BPM 計算與長條截斷問題。
- 修正開啟 PlayerOptions、SongOptions 後譜面還原問題。
- 修正多難度 STOP 位置問題。
- 新增播放前緩衝設定。
- 新增背景影片亮度調整功能。
- 新增預設 Reverse 設定。
- 使用玩家預設 NoteSkin 測試譜面。
- 測試譜面時顯示歌詞、判定與連擊數。
- 修正部分長條結尾造成的崩潰問題。
- 修正檔名過長時的介面跑版問題。

## 中文輸入

遊戲內支援 Windows 輸入法，可用於：

- 網路大廳聊天。
- 編輯器文字輸入欄位，例如 BPM 與 STOP。

輸入法只會在需要文字輸入的畫面啟用；組字期間的 Enter、Esc 與方向鍵會交由輸入法處理。
