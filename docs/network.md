# 網路功能

本專案提供網路大廳、玩家狀態同步、歌曲檔案傳送及獨立執行伺服器功能。

## 快速鍵

| 快速鍵 | 功能 |
| --- | --- |
| `F1` | 重讀 `connect` 資料夾 |
| `F4` | 跳到目前選擇的歌曲 |
| `F5` | 快速重讀歌曲 |
| `F8` | 開關玩家狀態列 |
| 同時按下左、右方向鍵 | 切換一般模式選歌 |

## 聊天室指令

| 指令 | 功能 |
| --- | --- |
| `/host <玩家名稱或玩家編號>` | 更換房主 |
| `/share [玩家編號]` | 傳送歌曲，不包含影片；未指定玩家時傳送給所有缺少檔案的玩家 |
| `/sharefull [玩家編號]` | 傳送歌曲，包含影片；未指定玩家時傳送給所有缺少檔案的玩家 |

## 功能說明

- 支援缺少歌曲檔案時的 `/share` 與 `/sharefull` 傳送功能。
- 支援玩家狀態列及結算畫面資訊同步。
- 結算畫面可同步玩家百分比與血量圖表。
- 支援大廳播放完整歌曲。
- 大廳背景可顯示目前選擇歌曲的背景圖。
- 會檢查所有玩家使用的譜面是否一致。
- 遊戲會強制使用不關門模式。

部分背景與選項功能需要主題提供對應的 `BGAnimation.ini`、選項清單及語言字串。

## 獨立執行伺服器

獨立伺服器具有視窗介面，可獨立於遊戲執行。使用方式、設定檔與建置方法請參閱 [`StandAloneServer/README.md`](../StandAloneServer/README.md)。

預設 TCP port 為 `8765`。若使用 VPN 或其他虛擬網路環境，請確認伺服器與所有客戶端可以互相連線。
